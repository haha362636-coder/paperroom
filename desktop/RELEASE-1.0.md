纸间 Paperroom 1.0.0

一张会呼吸的黑色皮面白板。便签、文件夹、手绘贴纸在一张有质感的皮面上自由摆放。
这是纸间的第一个正式版本，以 MIT 协议开源。

下载
- Mac 桌面版：Paperroom-1.0.0-mac-arm64.dmg（Apple Silicon，macOS 14 及以上）
- 网页版：无需安装，用支持 WebGL 的浏览器直接打开
- 宣传片：Paperroom-1.0-promo.mp4

主要功能
- 便签：按 N 新建，输入即自动保存（停笔 350ms 落盘）；标题留空时自动从正文提取。
- 皮质文件夹：把便签拖向袋口会吸附收纳，带 Web Audio 实时合成的扣合音效；点开后纸张以三维浮起，超过 6 张可以翻组。
- 手绘贴纸与简笔画：画笔颜色、粗细、撤销、清空，也能导入本机图片；贴纸可以贴在文件夹上，跟着一起拖动。
- 多白板工作台：每块白板独立保存笔记、文件夹、贴纸和偏好，并记住上次打开的一块。
- 挂绳工牌：绳段约束、重力、阻尼与释放惯性，支持鼠标、触摸和键盘方向键。
- 质感：物理材质、环境反射、柔光灯、清漆高光、SSAO 接触阴影与 MSAA 抗锯齿；微风让纸张和吊牌轻摆。
- 数据安全：保存在本机，保留上一份有效备份用于损坏恢复；可一键导出包含所有白板的 JSON 备份。

相比 1.0.0 RC 的修复
- 重叠便签按固定顺序绘制，消除同一平面的深度争抢；拖动时临时置顶。
- 用户便签和文件夹阅读页保持平整，微风不再扭曲文字。
- 普通便签在白板与文件夹内使用相同宽高，文字不再被拉伸。
- 调整窗口尺寸时保留当前位置和缩放，不再跳回初始视角。
- 长标题和正文在最后一行显示省略号；正确处理 CRLF 换行。
- 导出备份前立即提交待保存的文字；修正切换绘图笔记时的异步图片回填。
- 应用图标改为满铺不透明、alpha 全 255 的合规图标，macOS 26/27 不再给它套灰色方框。

安装（Mac）
1. 打开 DMG，把 Paperroom.app 拖进「应用程序」。
2. 本包为 ad-hoc 签名，未经 Apple 公证。第一次打开时如果系统阻止，
   请到「系统设置 → 隐私与安全性」，在页面下方找到 Paperroom，点「仍要打开」。
3. 从旧版升级会沿用原有笔记（Bundle ID 与本机 127.0.0.1:49173 来源保持不变）；升级前建议先导出一次备份。

已知限制
- 笔记只保存在当前设备上：网页版存在当前浏览器，桌面版存在应用自身，两者互不相通，也不跨设备同步。
- 仅支持 Apple Silicon Mac；Intel Mac 请使用网页版。
- 正常缩放和立体透视会改变整张便签在屏幕上的大小，这是相机缩放行为。
